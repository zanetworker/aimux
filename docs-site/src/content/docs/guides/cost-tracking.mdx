## How It Works

aimux tracks token usage (input, output, cache read, cache write) per agent and calculates cost using per-million-token pricing. Costs appear on agent cards, in the trace view per turn, and in the stats bar as a total.

## TUI

Press `$` to toggle cost-per-turn display in the trace view. The cost dashboard shows per-project breakdowns.

## Web Dashboard

Costs appear on agent cards and in the stats bar header. The trace panel shows per-turn cost when expanded.

## Unknown Models

Models not in the pricing table show `$0.00`. To add custom model pricing, submit a PR to `internal/cost/tracker.go`.
