## Agent List

| Key | Action |
|-----|--------|
| `Enter` | Open split view (trace + session) |
| `j` / `k` | Move selection down/up |
| `Tab` / `x` | Expand/collapse process tree |
| `*` | Pin/unpin session (star) |
| `B` | Open starred sessions tab |
| `S` | Open sessions browser |
| `t` | Open trace view |
| `c` | Open costs view |
| `/` | Search across agent traces |
| `$` | Toggle cost-per-turn display |
| `d` | Toggle diff view |
| `F` | Focus the agent's own terminal pane in iTerm2 (agents in tmux get the attach command instead) |
| `s` | Cycle sort order (name, cost, cpu, mem, age, model) |
| `m` | Mute/unmute notifications |
| `:new` | Open agent launcher |
| `?` | Show help overlay |
| `q` | Quit |

## Split View (Trace + Session)

With focus on the trace (the default when the split opens):

| Key | Action |
|-----|--------|
| `j` / `k` | Next/previous turn; inside an expanded turn, scroll it line by line |
| `J` / `K` | Scroll an expanded turn by 10 lines |
| `n` / `p` or `Space` | Next/previous turn, even when the current one is expanded |
| `Enter` | Expand or collapse the selected turn |
| `a` | Cycle the turn's label: GOOD, BAD, WASTE, none |
| `N` | Add a note to the current turn |
| `g` / `G` | Jump to the first/last turn |
| `c` | Collapse all turns |
| `/` | Filter turns (`Esc` clears the filter) |
| `e` | Open export menu |
| `Tab` | Switch focus between trace and session panes |
| `Ctrl+f` | Full-screen the focused pane |
| `Ctrl+]` or `Ctrl+g` | Close split view |

`Esc` does not close the split view: it is sent to the agent's terminal, so the agent's own shortcuts (cancel, reverse search) keep working.

## Sessions View

| Key | Action |
|-----|--------|
| `j` / `k` | Move selection down/up |
| `g` / `G` | Jump to top/bottom |
| `Enter` | Resume selected session |
| `/` | Filter by title, prompt, project, tags |
| `P` | Filter by directory path |
| `F` | Deep content search inside session files (ranked index; see note below) |
| `s` | Cycle sort order (age, cost, turns, title, failure mode) |
| `A` | Toggle between current directory and all projects |
| `a` / `v` | Cycle annotation (achieved, partial, failed, abandoned) |
| `f` | Set failure-mode tag |
| `N` | Add/edit note |
| `C` | Copy session ID to clipboard |
| `p` | Toggle trace preview pane |
| `d` | Delete session (with confirmation) |
| `D` | Cleanup mode (find duplicates/empty sessions) |
| `H` | Show/hide subagent sessions |
| `Esc` | Clear filters (path first, then text), then exit view |

`F` searches the same ranked index as `aimux sessions`: keyword ranking, plus semantic ranking when `OPENAI_API_KEY` is set. The TUI refreshes the index when it starts and embeds changed sessions in the background, so a search doesn't wait for them; only a new query's own embedding calls the API (cached after the first time). New messages match by keyword right away and usually join semantic ranking within seconds. If more than 20 sessions changed at once, they are not embedded automatically; run `aimux sessions index` to catch up. If the embedding API is unreachable, the work stays queued and the next search retries it, even if no files changed.

## Cross-Session Search

Press `/` from the agent list to search across all active agent traces. Type a query (file name, function, error message) and aimux highlights matching sessions. This searches inside the trace content, not just session titles.

## Command Palette

Type `:` to open the command palette:

| Command | Action |
|---------|--------|
| `:new` | Launch new agent session |
| `:export-otel` | Export current trace via OTEL |
