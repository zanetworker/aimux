## Install

```bash
# Homebrew (macOS/Linux)
brew install zanetworker/aimux/aimux

# From source
git clone https://github.com/zanetworker/aimux.git
cd aimux
make install       # builds and copies to /usr/local/bin
```

## Requirements

- **tmux** - required for split-pane session embedding and agent launch
- **Go 1.24+** - only if building from source
- Running AI coding agents: Claude Code or Codex CLI

## Launch the TUI

```bash
aimux
```

aimux auto-discovers running Claude and Codex processes. The agent table refreshes every 2 seconds.

## Launch the Web Dashboard

```bash
aimux web              # web dashboard on port 9090
aimux web --port 8080  # custom port
aimux --web            # both TUI and web simultaneously
```

Open `http://localhost:9090` in your browser.

## CLI Commands

| Command | Description |
|---------|-------------|
| `aimux` | Launch TUI dashboard |
| `aimux web` | Launch web dashboard (default port 3000) |
| `aimux --web` | Launch both TUI and web |
| `aimux agents --json` | List running agents (structured output) |
| `aimux sessions --list` | List session history |
| `aimux sessions "query" --list` | Search sessions by keyword |
| `aimux spawn claude --dir ./proj` | Start a new agent session |
| `aimux resume <id>` | Resume a previous session |
| `aimux jump <id>` | Bring a running session's iTerm2 pane to the front (session ID, unique prefix or PID) |
| `aimux setup` | Check every concern and run only the missing setup steps (tool registry, clients, sandbox, Chrome host); on a terminal, offer to review changed tools |
| `aimux doctor` | Read-only checks with one fix per problem; exit 1 on any failure, warnings exit 0 ([Troubleshooting](/guides/troubleshooting/)) |
| `aimux agent-context` | Machine-readable CLI schema for agents |
| `aimux profile save <name>` | Save a named configuration bundle (v1; `aimux profile migrate` converts it to a [profile](/guides/profiles/)) |
| `aimux feedback "text"` | Report CLI friction |
| `aimux version --json` | Print version info |

All data commands support `--json` for structured output. See [Agent Usage](/guides/agent-usage/) for the full reference.

## Set up Wingman and the sandboxed profiles

```bash
aimux setup --extension-id <id>   # the id is in chrome://extensions once the Wingman extension is loaded
aimux doctor                      # read-only: what is still wrong, and the fix for each
```

`aimux setup` checks the sandbox, tools, router, browser and OpenShell gateway and runs only what is missing: it asks before each step on a terminal, and `--yes` runs them without asking. It ends with one line per concern (`✓`, `!` or `✗`) and a `Next:` line for each problem. Run it again any time; with nothing missing it changes nothing. It never approves a tool unless you answer yes to that tool's diff on a terminal. The [Wingman guide](/guides/wingman/) has the details and [Troubleshooting](/guides/troubleshooting/) lists every `aimux doctor` check.

## Quick Tour

1. **Start some agents** - Run Claude Code or Codex in other terminals
2. **Open aimux** - They appear automatically in the dashboard
3. **Select an agent** - Press Enter (TUI) or click a card (web) to see its trace
4. **Annotate** - Mark turns as good/bad/waste to build eval datasets
5. **Export** - Send traces to MLflow via OTEL, or save as JSONL
